TECHNOLOGY JUSTIFICATIONS

Next.js 16 (App Router)

Framework

Full-stack monolith on a single deployment: SSR marketing pages for SEO, API routes for backend logic, and React Server Components for dashboard performance. The App Router's streaming and parallel data fetching eliminate waterfall requests. Vercel's edge network handles global CDN without configuration.

Rejected: separate frontend/backend (deployment complexity, CORS), Remix (smaller ecosystem), SvelteKit (team hiring pool)

6-Model Gemini Fallback Chain

AI Reliability

LLM APIs are inherently unreliable at the individual model level. The fallback chain (gemini-2.5-flash → 2.5-flash-preview → 2.0-flash → 2.0-flash-lite → 1.5-pro → 1.5-flash) with dead-model tracking achieves near-100% availability. If a model returns 3 consecutive errors, it's skipped for 5 minutes — the system degrades gracefully rather than failing.

Rejected: single model (fragile), OpenAI (higher cost per token), local LLM (insufficient quality for resume analysis)

SQLite via Turso

Database

SQLite eliminates connection pooling complexity, cold starts, and the operational overhead of managed Postgres. Turso distributes SQLite globally with automatic replication — read latency matches the user's nearest edge location. Row-Level Security wrapper enforces user isolation at the ORM layer, preventing multi-tenant data leaks structurally.

Rejected: Postgres/Neon (connection pooling overhead for serverless), PlanetScale (MySQL quirks), Supabase (over-provisioned for early stage)

Edge Proxy (9 Security Controls)

Security Architecture

A single proxy.ts file runs before every request — maintenance mode, auth gate, rate limiting, CSRF, CSP headers, CORS, body size limits, request tracing, and API protection. This architecture guarantees security controls can't be bypassed by adding new routes. New endpoints inherit all 9 controls automatically.

Rejected: per-route middleware (inconsistent coverage), WAF-only (no app-layer auth), third-party proxy (latency + cost)

Redis (Upstash)

Rate Limiting + Caching

Serverless Redis via Upstash provides sub-millisecond rate limit checks without persistent connections. Burst rate limiting (30 req/min on auth routes) and monthly plan caps (free tier: 10 AI requests/month) are enforced atomically. The serverless pricing model means zero cost when idle.

Rejected: in-memory (resets on cold start), database counters (too slow for per-request checks), Cloudflare KV (eventual consistency)

Chrome Extension (Manifest V3)

Job Board Integration

Instead of building scrapers for every job board, the extension meets users where they already browse. A floating badge on supported sites captures structured job data with one click and syncs to the user's tracker via 3 dedicated API endpoints. Manifest V3 ensures Chrome Web Store compliance and service worker lifecycle.

Rejected: web scrapers (brittle, ToS violations), browser bookmarklet (limited capabilities), manual entry (friction kills adoption)

Stripe (Hosted Checkout)

Billing

Stripe's hosted checkout eliminates PCI compliance scope — payment details never touch the application. Webhook-driven state management ensures the database plan state stays in sync even when webhook delivery fails (reconciliation endpoint as safety net). Supports subscription lifecycle: creation, renewal, cancellation, and payment failure recovery.

Rejected: Paddle (lower market penetration), LemonSqueezy (limited payment methods), self-hosted (PCI nightmare)

8 Prompt Templates

AI Architecture

Each AI action (resume analysis, full rebuild, deep tailor, career pivot, cover letter, interview prep, job match, LinkedIn outreach) uses a domain-specific prompt with structured output requirements. This produces consistent, parseable responses rather than free-form text. Prompt engineering is the most cost-effective way to improve AI quality — no fine-tuning required.

Rejected: single generic prompt (inconsistent output), fine-tuned model (expensive, fragile), multiple providers (integration complexity)

Sentry + PostHog

Observability

Sentry captures every error with full stack traces, request context, and user session replay — essential for debugging AI failures in production. PostHog provides product analytics (feature usage, funnel conversion, A/B testing) without sending data to Google. Both have generous free tiers for early-stage SaaS.

Rejected: LogRocket (expensive at scale), Datadog (enterprise pricing), self-hosted (operational overhead)

Vercel Deployment

Infrastructure

Vercel provides zero-config deployment with automatic HTTPS, global CDN, serverless functions that scale to zero, preview deployments per PR, and native Next.js optimization. The serverless model means no idle cost — the application handles traffic spikes automatically without capacity planning.

Rejected: AWS (operational complexity), Railway (less Next.js optimization), self-hosted (DevOps overhead for solo founder)
